# PopX React Application

A responsive React.js web application based on the PopX UI design. The application includes user registration, login authentication, profile image upload, and account settings pages. Navigation is implemented using React Router, and user data is managed with Local Storage.

## Features
- User Registration
- User Login
- Profile Image Upload
- Account Settings Page
- React Router Navigation
- Responsive Design
- Local Storage Data Persistence

## Technologies Used
- React.js
- React Router DOM
- CSS3
- JavaScript (ES6)
